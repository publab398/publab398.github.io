## まずは一試合。

**Free For All**は、全員が敵になる個人戦。**Hardpoint**は、時間とともに移動する拠点を奪い合うチーム戦です。

ひとりで試すなら、メインメニューの**PRACTICE**からモードを選び、ロビーの**AUTO FILL**でBotを追加して**START MATCH**。武器やアビリティは**LOADOUT**から変更できます。

友達と遊ぶなら、**PLAY ONLINE**でロビーを作成するか、一覧から参加します。オンライン対戦では、ホストと参加者が**同じバージョンのビルド**を使ってください。

## 基本操作

| 操作 | 既定のキー |
| --- | --- |
| 移動 | W / A / S / D |
| スプリント | 左Shift |
| しゃがみ・スライディング | 左Ctrl（スプリント中にスライディング） |
| ジャンプ | Space |
| 射撃・照準 | 左クリック / 右クリック |
| リロード | R |
| 戦術アビリティ | Q |
| 特殊アビリティ | マウス5（サイドボタン） |
| キルストリーク・Ultimate | X / C / V |
| スコアボード | Tab |
| ポーズ | Esc |

キー割り当ては**SETTINGS → CONTROLS**から変更できます。

## テストビルドについて

Windows向けの開発中ビルドです。ダウンロードしたZIPを展開し、`ProjectCDX.exe`を起動します。動作環境の詳細は、配布開始時に掲載します。

紹介している内容や画像は開発時点のものです。新しいビルドや注目のアップデートは、このページの[お知らせ](/project-cdx/#news)で紹介します。

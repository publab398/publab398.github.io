**Hawkeye（ホークアイ）**は、メイン武器として選べるセミオートのリボルバーです。黒い金属の銃身と木製グリップに、小型のレッドドットサイトを組み合わせています。左クリックするたびに一発ずつ発射します。

## 跳ねる、戻る、次を撃つ

一発ごとの威力が高く、近距離では胴への2発で敵を倒せます。距離が離れると威力が下がるため、中距離ではヘッドショットを交ぜることが大切になります。ヘッドショット一発で倒せる武器ではありません。

撃つと銃口が大きく跳ね上がり、その後に照準が戻ります。急いで連打するよりも、**照準の戻りを見ながら一発ずつ当てる**リズムを試してみてください。敵を外したときは、遮蔽物で身を隠して次の射撃に備えましょう。

## スピードローダーでまとめて装填

リロードではシリンダーを横へ開き、薬莢を抜いてから、スピードローダーで弾をまとめて装填します。残弾があるときも、撃ち切ったときもリロード時間は同じです。

![Hawkeyeのリロード中の開発画面。横に開いたシリンダーと、装填された弾の底が見える。](/assets/project-cdx-weapon-hawkeye-reload.png)

| 項目 | 現在の設定 |
| --- | --- |
| 射撃方式 | セミオート |
| 装弾数 | 9発 |
| 最大連射速度 | 180発／分 |
| リロード時間 | 2.1秒 |

## 射撃場でリズムをつかむ

**LOADOUT → WEAPONS**からHawkeyeを選べます。試合中に武器を変更した場合は、次のリスポーンから反映されます。

**PRACTICE → Shooting Range**で、近くのダミーに胴撃ちを当ててから、距離を伸ばして頭も狙ってみてください。照準は右クリック、リロードはR、武器を眺めるInspectはNが既定の操作です。キーは**SETTINGS → CONTROLS**から変更できます。

画像と性能は開発時点のものです。装弾数や威力などは、今後の調整で変わることがあります。

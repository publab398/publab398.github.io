Project-CDXでは、**8種類のメイン武器**から1つを選んで使います。連射の速いSMGから、散弾とライフルを切り替える銃まで、それぞれ使い方が違います。

武器は**LOADOUT → WEAPONS**で変更できます。試合中に変更した場合は、次のリスポーンから反映されます。

## 選べる武器

| 武器 | 種類 | 特徴 |
| --- | --- | --- |
| **ARC-16** | アサルトライフル | フルオートのライフル。近距離から中距離まで、最初に試しやすい1本です。 |
| **Venom** | サブマシンガン | 連射が速く、近距離での撃ち合いやスライディングしながらの攻撃に向きます。 |
| **Raven K27** | バトルライフル | 1発の威力が高いフルオート。等倍ホロサイトで狙い、強めの反動を抑えて撃ちます。 |
| **LG11** | ライトマシンガン | 47発のパンマガジンと2倍スコープ。長く撃ち続けられますが、リロードは長めです。 |
| **P08C** | ピストルカービン | ストックと3倍スコープを付けた小型のフルオート銃。腰撃ちの精度も高く、近距離で威力を発揮します。 |
| **AWX** | スナイパーライフル | 6倍スコープを使うボルトアクション。頭に当たれば一撃ですが、1発ごとに次弾を装填します。 |
| **Drilling** | ショットガン | 散弾銃身2本とライフル銃身1本を持つ銃。距離に合わせて射撃モードを切り替えます。 |
| **Pulse Driver** | テック武器 | 腰撃ち専用のコイルガン。移動中や空中でも弾がばらけず、飛んでいくエネルギー弾で攻撃します。 |

## 最初は何を使う？

迷ったら、まずは**ARC-16**で操作を覚えると試しやすいです。近い距離で動きながら戦いたければVenom、スコープで遠くを狙いたければAWX、といったように持ち替えてみてください。

Raven K27は、長く連射するよりも数発ずつ区切って撃つと反動を抑えやすくなります。LG11は、照準を合わせて撃つと腰撃ちより弾をまとめられます。

## Drillingの切り替え

**T**で散弾とライフルを切り替えます。散弾は近くの敵をまとめて狙うとき、ライフルは少し離れた敵を狙うときに使えます。

散弾は2発、ライフルは1発を別々に装填しています。散弾を撃ち切っても、ライフルの弾が残っていれば切り替えて撃てます。使った銃身によってリロードの動作も変わります。

## Pulse Driverは腰撃ち専用

右クリックで照準を合わせる武器とは違い、Pulse Driverは腰撃ちのまま使います。移動中やジャンプ中でも弾がばらけないのが特徴です。

ただし、弾は瞬時には届きません。横に動く敵には、進む方向の少し先を狙ってみてください。

## 射撃場で比べてみよう

**PRACTICE → Shooting Range**から射撃場へ入れます。距離の違うダミーで、反動やスコープ、当てやすさを比べられます。

- **左クリック**で射撃、**右クリック**で照準、**R**でリロード。
- **T**でDrillingの射撃モードを切り替え。
- **N**で武器を眺めるInspect。

上のキーは既定の設定です。SETTINGS → CONTROLSから変更できます。

ロビーの武器ルールによっては、一部の武器がLOCKEDになります。性能や装弾数は開発中の調整で変わることがあります。

## 射撃場で試す

**PRACTICE → Shooting Range**で、距離の違うダミーを使って反動やスコープを比べられます。

| 操作 | 既定のキー |
| --- | --- |
| 射撃 / 照準 | 左クリック / 右クリック |
| リロード | R |
| Drillingのモード切替 | T |
| 武器を眺めるInspect | N |

キー変更は**SETTINGS → CONTROLS**から。ロビーの武器ルールによっては一部がLOCKEDになります。性能・装弾数は開発中の調整で変わります。

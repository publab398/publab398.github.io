Project-CDXのメインモードは**Hardpoint**です。ALPHAとBRAVOの2チームに分かれて、時間とともに移動する拠点を取り合います。敵を倒して入口を開けたり、味方がいる拠点を守ったりしながら、チームの得点を増やしていきます。

## どうすれば得点が入る？

**拠点の中に自分のチームだけがいる間、1秒ごとに1点**入ります。標準設定では、先に200点に届いたチームの勝ちです。人数を増やして拠点に入っても、得点の速さは変わりません。

| 拠点の中にいる人 | 得点 |
| --- | --- |
| 自分のチームだけ | 自分のチームに入る |
| 相手のチームだけ | 相手のチームに入る |
| 両方のチーム | CONTESTED。両チームとも止まる |
| 誰もいない | NEUTRAL。両チームとも入らない |

キル数だけでは勝敗が決まりません。相手に押されていても、拠点の中に入れば相手の得点を止められます。味方がすでに入っているときは、入口や周囲を守る役もできます。

## 拠点は順番に移動

標準設定では、拠点は**60秒ごと**にP1 → P2 → P3 → P4 → P5 → P1の順で移動します。残り10秒になると、次の拠点が予告されます。

今の拠点を最後まで守るか、次の拠点へ先に向かうかも試合のポイントです。慣れるまでは、次の拠点が表示されたら場所を確認してみてください。

スコア上限と拠点の時間はロビーで変更できます。上の200点・60秒は標準設定です。

## 画面で見るところ

- **画面上部**：両チームのスコア、現在の拠点、残り時間。
- **拠点のマーカー**：向かう場所の目印。
- **左上のミニマップ**：自分、味方、拠点の位置。発砲した敵も表示されます。
- **Tabのスコアボード**：試合中の成績と、自分のUltimateのチャージ。

自分のチームは青、相手は赤で表示されます。Hardpointでは、味方への攻撃でダメージは入りません。

## 最初の1試合

**PRACTICE → Hardpoint**でロビーを開き、**AUTO FILL**でBotを追加して**START MATCH**を選びます。まずは拠点のマーカーを追いかけて、得点が入る場所を覚えるところから試せます。

武器や装備はLOADOUTで変更できます。[武器の紹介](/project-cdx/features/weapons/)と、[エアストの使い方](/project-cdx/features/airstrike/)も載せています。

## サブモードと射撃場

**Free For All（FFA）** は、全員が敵になる個人戦です。標準設定では先に20キルした人が勝ちます。チームや拠点を気にせず撃ち合いたいときに遊べます。

**Shooting Range**は1人用の射撃場です。距離の違うダミーを撃ったり、武器や移動を試したりできます。どちらもPRACTICEから選べます。

紹介内容は開発時点のものです。
